# Phase 3: progression explorer

The initial tag/scale-filtered suggestion browser has been replaced by the
[122-idea HOME progression explorer](PROGRESSION-EXPLORER.md).

Current scope: complete-list SELECT browsing, automatic key/scale/meter setup,
K1 rhythm selection, visible tags and meter, live chord matching, seven-mode
coverage and a broad catalog including verified Paramore section seeds.
Generation, editing, a guided playback engine and sequencer handoff remain
outside this change. The app's full visual redesign is a separate effort.

See the explorer guide for controls, the complete catalog, source references,
record compatibility and verification. No device release or flashing is implied.
