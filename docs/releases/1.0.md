# CORD 1.0

CORD's first 1.0 release brings the current custom firmware and physical transport LED fixes together in one installable build.

- **PLAY is green while running and orange while stopped.** Orange blinks while waiting for external clock or after clock loss. REC is red during recording and blinks during count-in. These are physical LED outputs; the browser mirrors them.
- **Nine HOME pages:** Core, Sound, Texture, Groove, Perform, Loop, Mix, Variations and Keyboard/Harmony. ALGORITHM cycles them; Harmony stays last.
- **Root-only progression cues** follow the shared phrase clock in Drums only mode and the SEQ workspace. Live roots take over the steady cue; the next root keeps its blink.
- **Harmony and Drum variations** apply through the accompaniment next-bar queue, including Undo.
- **Auto Harmony defaults to On** for fresh settings and Reset to Defaults. Existing saved On/Off preferences are preserved.
- Separate bounded melodic/percussion budgets reduce static voice competition between large chords and drums. Existing device overload protection remains active.
- Visual ARP, thirteen FX presets, protected phrase editing, Chord Lab, six saved ideas, three recent manual recordings, USB stereo/stem capture, and Devil/Ember or Cat/Plum presentation remain available.
- The preview includes a **CORD installer** with latest-release selection, custom `.fwsc` files, checksum checks, backup, restore and recovery controls.

**Updating from 0.6-chase14:** install this 1.0 package to get the physical green/orange PLAY behavior. The earlier package does not contain that change.

[Install CORD](https://chasedeanda.github.io/cord-fm1/install/) · [Play in your browser](https://chasedeanda.github.io/cord-fm1/play/) · [Complete guide](https://github.com/chasedeanda/cord-fm1#readme)

The package is named `cord-1.0.fwsc`. The device retains the compatible `CoralFlower 1.0` INFO family string and `FM-1_930` package identity so the updater and backups continue to recognize it. No FM-1 has been flashed automatically; physical LED behavior still needs confirmation on the device.
