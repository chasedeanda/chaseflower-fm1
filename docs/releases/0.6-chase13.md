# Chase FM-1 0.6-chase13

- **Eight HOME toolbars:** Core → Sound → Texture → Groove → Perform → Loop → Mix → Harmony/Keyboard.
  Turn ALGORITHM forward/backward or tap HOME to cycle. Harmony/Keyboard is always last.
- **Loop and Mix on HOME:** The same controls and state as SEQ → Loop/Mix, with read-only full-phrase
  First/Last endpoints. SELECT continues browsing ideas and playback keeps the same transport.
- **Boot appears once:** Remove the early animated splash that was cleared before the live UI began.
  Motion Off retains its static splash. The optional chime waits 180 ms for startup work to settle.
- **Warmer rising strum:** Six notes (D3 F3 A3 C4 F4 A4), 2.2 seconds including a softer tail,
  about 6.6 dB higher measured peak than the previous short chime. MASTER and BOOT SND still control it.
  Note setup is moved out of the per-sample loop. Playing a note still cancels/fades the chime.
- **Root-only key guide:** Current/next chord cues light only roots, not all chord tones.
  The stronger next-root pulse wins over a currently held/lit root, including repeated roots.
  Upper keys retain their actual modifier state.
- Includes the latest main Harmony controls, mascot appearance, accompaniment and ARP changes.
