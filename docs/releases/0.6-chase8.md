# Chase FM-1 0.6-chase8

The chord-first update: a native Instrument Teal interface, progression playback,
editable phrases, saved musical ideas and Chord Lab. Start with the
[five-minute beat walkthrough](../../README.md#make-a-beat-in-your-first-five-minutes).

## What changed since 0.6-chase7

- **Native screens throughout.** HOME, sound/envelope/FM6/VA, FX, recordings,
  system, diagnostics and recovery now use the new layouts. The default build
  opens straight to HOME/Core; the older Bass/Bonfire scenes and fish intro are
  omitted. Motion has one On/Off control; On follows real output/activity and
  musical events, and Off settles visual animation.
- **Four HOME banks.** HOME cycles Core, Sound, Texture and Groove. The bottom
  labels show the four controls. SELECT browses the progression catalogue from
  every bank; sound, FX mix, kit, swing and part levels are available while playing.
- **Shared-clock accompaniment.** SEQ opens Groove/Loop/Mix/Click; ALGORITHM
  changes tabs. Play chords with drums or drums alone, repeat the complete phrase
  or play once, and add Click alongside the groove. Applied and queued changes,
  actual playhead and selected focus are distinct. External wait/loss/Start/Continue
  use the same transport.
- **Protected sixteen-slot editor.** EDIT from HOME/Accompaniment opens a working
  copy. Edit chord quality/color, timing/gate/tie, voicing/register and bass;
  insert, duplicate, remove with confirmation, or undo. Quiet checkpoints recover
  the working draft without modifying factory originals.
- **Songs.** SAVE from HOME, Accompaniment, the editor or Lab opens the library.
  Save six separate ideas with phrase/setup, chord and bass patches/edits,
  Harmony, arp, levels and effects. Stop/release and wait for Saved; Pending is
  still RAM-only. Load, duplicate, rename or delete ideas, and open existing
  fixed-note recordings from the same list. Each Save current creates a new copy.
- **Chord Lab.** SEL on HOME opens Notes & Degree, Intervals, Compare and Next
  Chord. Inspect actual/last/planned chords, hear deliberate A/B comparisons, or
  explore three offline continuation candidates. Choose an explicit destination
  before EDIT replaces a slot; phrase Undo restores the previous draft.
- **Latest-three manual recordings.** REC counts in, then records your own
  playing over the groove; it stops automatic progression chords. Completed
  takes are one to eight bars. Newest is always 1; default rotation replaces the
  oldest only after a successful new take. AUTO DEL Off protects a full set.
  Cancel preserves previous takes. Clear uses a counted hold.
- **Expanded musical material.** The catalogue includes additional cover-section
  ideas with exact source intervals and slash bass, alongside the existing
  sound banks, synthesized drum kits, FX presets and Auto Harmony controls.

**Control changes worth remembering:** HOME cycles banks; SEQ opens Accompaniment;
EDIT opens the phrase editor; SEL opens Lab; SAVE opens Songs. Deep sound editing
is **ENV → EDIT**, and chord-button assignments are **GLO → Harmony → SEL**.
Sound-only SAVE remains on sound/envelope pages. Catalogue favourites remain in
**GLO → Browse**. See the [README control reference](../../README.md#get-around-the-new-interface).

## Install

Download **`coralflower-0.6-chase8.fwsc`** from this release. Save a current backup,
then open <https://ficusficusov.github.io/CoralFlower/#own> in Chrome or Edge.
Under **Another version, or a build of your own**, choose this `.fwsc` and check
the selected filename before installing. Keep USB connected until restart.
The separate app `.bin` and source archives are not installer packages.

INFO reports **CoralFlower 0.6-chase8**; the default screen is native HOME/Core.
Package identity stays **FM-1_930** and the existing USB names remain compatible.
The firmware does not add computer-to-FM-1 audio playback.

## Saved data and remaining scope

Existing sound/settings layouts and archived A–H patterns remain protected.
Legacy A–C can populate the three active recordings; D–H and the old arrangement
remain archived/exportable rather than silently mapped into the live slots.
The working checkpoint, new recordings/policy and six Songs use additional
versioned backup records. Use updated backup/restore tools that understand these
records, and retain a pre-upgrade backup for older firmware.

[Recording compatibility](../RECORDINGS.md) · [Songs storage and recall](../SONGS-LIBRARY.md)
· [Draft recovery](../design/chord-first/native-editor/README.md)

This release keeps the manual recorder. Arranged direct capture, recording
rename/duplicate, broader bulk-clear workflows, running complete-idea recall and
the separate chord-library picker remain future work. Songs currently holds six
ideas; Save current does not update an existing row in place.

## Validation

The release is built from its tagged source with the actual JieLi toolchain.
Build checks cover linked memory bounds, executable RAM/MMIO restrictions,
protected boot-stub/loader layout and package construction. The full host CI
suite covers native pages/motion, accompaniment/clock ownership, editor/checkpoint
power cuts, Songs persistence/recall, Lab audition/insertion, recording/backup
ordering, Auto Harmony, installer compatibility and USB/audio regressions.

`SHA256SUMS` covers the installable firmware and application image. `LICENSE`,
`LICENSING.md` and `LICENSES.zip` accompany the release assets. Native captures
are emulator renders, not hardware photographs. Physical TFT readability,
listening, input/CPU timing, power-cycle/recall and sustained USB use of the
combined build remain pending; no hardware flash or device test is claimed here.
