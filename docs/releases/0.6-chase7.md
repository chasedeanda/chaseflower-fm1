# Chase FM-1 0.6-chase7

Built from main with the merged HOME progression explorer, contextual variations and live FX preset auditioning.

## New since 0.6-chase6

- **100 progression ideas on HOME.** Progressions is the default main view. SELECT browses the complete catalog,
  setting each idea's starting key, scale and meter. Matching chord cards light while you play. K1 chooses a
  groove in the current meter; PLAY controls transport. The new 3/4 Waltz brings the drum bank to 39 patterns.
- **Four main screen options.** ALGORITHM cycles Progressions, Bass, Bonfire and Nothing. Progressions and
  Nothing skip scene animation. HOME still cycles the main, Chord, Keyboard and Diagnostics views.
- **Contextual variations with undo.** Open GLO → Variation. K1 chooses Harmony, Arp, Drums, FX, Sound or Scale;
  K2 chooses Subtle, Musical or Chaos; turn K3 right to generate and K4 right to undo. Changes affect only the
  selected context. Undo lasts for the session. Recorded patterns and saved presets are preserved.
- **Hear FX while browsing.** Press FX again from the editor to open the preset browser. SELECT immediately
  auditions each valid preset. K2 CLEAR FX fades to dry, including running tails; K3 UNDO FX restores the previous
  chain. There are 40 factory chains and 16 optional user slots. Empty slots leave the current sound playing.

Auto Harmony remains a simple **GLO → Harmony → K1 On/Off** choice. It generates complete major/minor chords
with button-selected extensions. Use Basic/Full quantization with a seven-note scale. The beat-reactive Bass and
Bonfire scenes, Chase FM-1 startup, sound banks, refreshed grooves, sequencer, Diagnostics and six-channel USB
recording remain included.

For full controls, see the [progression explorer](../PROGRESSION-EXPLORER.md), [variations](../PHASE4-PLAN.md),
[FX presets](../FX-PRESETS.md), [Auto Harmony](../AUTO-HARMONY.md) and [drum bank](../DRUM-LOOPS.md) guides.

## Install

Download **coralflower-0.6-chase7.fwsc**. Save a current backup, then open
<https://ficusficusov.github.io/CoralFlower/#own> in Chrome or Edge. Under **Another version, or a build of your
own**, choose this `.fwsc` and verify the selected filename before installing. The separate app `.bin` and source
archives are not installer packages. INFO reports **CoralFlower 0.6-chase7**; startup says **Chase FM-1**.

## Validation

The tagged-source release uses the JieLi device toolchain with memory-layout, protected-sector and package checks.
Automated host checks cover progression browsing, variation bounds and undo, FX audition/clear/restore, drum
compatibility, Auto Harmony, saved data, visuals, diagnostics and physical/six-channel USB audio comparisons.

`SHA256SUMS` covers the firmware and inspectable application image; licence files accompany the assets. These
checks do not establish physical-device sound, stack headroom, real-time timing or sustained USB recording.
Those checks remain for the FM-1. Keep a current backup and the previous known-good package available.
