# Chase FM-1 0.6-chase4

The combined release from main, including the approved visuals and diagnostics features alongside the existing
chase3 sounds, 6/8 grooves, sequencing and six-channel USB recording.

## New graphics and controls

- Swimming bass with body and fin motion, bubbles and four small baitfish drifting in the background.
- A taller triangular bonfire with golden flame ribbons and rising embers.
- Turn ALGORITHM on HOME to switch Bass ↔ Bonfire without changing Top Lock or interrupting held chords/playback.
  Bass is the default, and the scene is saved across power-off and backup/restore.
- Chase FM-1 startup: the bass swims by, jumps out of a moonlit lake, splashes down, and completely leaves the screen
  before the intro ends. The animation is 2.4 seconds and can be skipped with any input.
- HOME cycles Scene → Chord → Keyboard → Diagnostics. FX and Sequencer keep their contextual ALGORITHM controls.

## Diagnostics

The fourth HOME view shows audio workload/timing, UI cadence, linked memory and USB status. Use GLO → Diagnostics
for pages, hold/reset and sampling rate. A read-only MIDI command and `tools/diagnostics.py` support repeatable
performance reports. The dashboard distinguishes emulator measurements from physical-device readings.

Read [the diagnostics guide](../DIAGNOSTICS.md) for definitions and measurement limits, [the visuals guide](../VISUALS.md)
for scene controls, and [the chase3 guide](../CHASE3.md) for sound banks and 6/8 grooves.

## Installation and compatibility

Install **`coralflower-0.6-chase4.fwsc`**. Save a current backup first. In the upstream installer's
**Another version, or a build of your own** section, choose this file explicitly and verify its name before pressing
Install. The default upstream package is a different build. The separate app `.bin` is supplied for inspection;
do not select it in the installer.

INFO reports `CoralFlower 0.6-chase4` so the installer recognizes the firmware family; the startup title is **Chase FM-1**.
The package remains `FM-1_930`, USB device names are unchanged, and the 188-byte settings/backup format is preserved.
Older mode settings load in Top Lock; existing Top chord-button definitions, saved sounds and patterns are retained.
Recordings and diagnostics use the existing USB MIDI/audio connection.

`SHA256SUMS` covers the firmware package and application image. The release also includes `LICENSE`, `LICENSING.md`
and `LICENSES.zip`. GitHub's source archives identify the exact tagged source.

## Validation and recovery

The release is built from the tagged main revision with the JieLi device toolchain and checked for protected-sector,
package-structure and linker-region correctness. Host CI covers saved settings, scene/diagnostics controls, the full
bass exit, audio continuity, library/timing, USB capture, backup and storage behavior. Physical boot, panel appearance,
USB enumeration and timing under your actual musical workload remain device checks after installation.

To enter the existing update loader, hold OCT− + OCT+ + HOME for five seconds. Releasing during the countdown cancels.
The unchanged boot stub also supports rescue with OCT− held alone at power-on. Keep a known-good firmware package
and your backup available; see the [earlier recovery guide](../CHASEFLOWER.md#recovery) for details.
