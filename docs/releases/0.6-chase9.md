# Chase FM-1 0.6-chase9

HOME feedback fixes for [0.6-chase8](0.6-chase8.md). Songs, Chord Lab, the editor,
recording policy and musical controls retain their existing behavior.

- **Fix missing HOME rings on hardware.** Audio and UI uptime start at different
  points during boot. The old freshness check compared those clocks directly
  and could discard every valid output level. Freshness now follows publication
  progress in UI time, with a bounded timeout if the audio owner stops updating.
- **Catch short hits.** A bounded output-peak window lets the display catch drum
  transients between frames. It is consumed by the existing snapshot and expires
  after 100 ms, so hidden/late frames do not replay old hits.
- **Clearer motion.** Two visible rings respond to actual output and accepted
  beat phase. A small moving indicator beside the top-right status follows the
  shared clock; live notes/tails show output activity without inventing a BPM.
- **Live chord matching.** Matching progression cards light while you play,
  including repeated matches and HOLD. The underline continues to show the actual
  playback position. Matching respects chord quality/source extensions and ignores
  inversion; silence/single-note fallback do not light chord matches.

Enable animation in **GLO → Display → K4 Motion On**. At zero output volume the
rings settle; a running transport can still show its clock indicator. Motion Off
cancels animation immediately, while actual chord-match highlighting still updates.

Download **`coralflower-0.6-chase9.fwsc`**, back up current data, then choose that
file in the [custom-build installer](https://ficusficusov.github.io/CoralFlower/#own).
The `.bin` is an inspectable application image, not the installer package. INFO
reports **CoralFlower 0.6-chase9**; package identity remains **FM-1_930**.

Regression checks cover different clock origins, stalled metadata, short hits,
real header pixels/beat phases, live/repeated/source matches, release and Motion
Off. Host comparisons verify unchanged speaker output, all six USB channels and
MIDI at 44.1/48 kHz. Actual JieLi link/package checks and CI are required before
publication. Physical TFT readability, listening and timing remain device checks.
