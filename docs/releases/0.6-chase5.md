# Chase FM-1 0.6-chase5

Adds the merged **Auto Harmony** feature to the combined main release. The bass/bonfire scenes, Chase FM-1 boot
animation, Diagnostics, ambient/lo-fi sound banks, 6/8 grooves, sequencing and six-channel USB recording remain included.

## Turn on Auto Harmony

Open **GLO → Harmony**, then turn **K1 to Auto**. Manual remains the default when no Harmony preferences have been saved.

| Knob | Setting |
| --- | --- |
| K1 | Manual / Auto |
| K2 | Basic / Rich / Dreamy / Custom |
| K3 | Root / Smooth voicing |
| K4 | Layout-following modifier persistence / Moment override |

Auto builds chords by stacking thirds from the selected seven-note scale. In C major, I–V–vi–IV gives
C–G–Am–F without selecting Major or Minor; a seventh modifier gives Cmaj7–G7–Am7–Fmaj7. Basic uses triads,
Rich adds the scale seventh, and Dreamy adds the seventh and ninth. Custom uses the extension selected with SEL K2.

The upper keys become configurable smart modifiers, including extensions, suspensions and quality overrides.
The Chase FM-1 UI still uses Top Lock. HOLD sustains roots independently of modifier persistence, and the Moment
override makes modifiers temporary even in Top Lock. ALGORITHM still selects Bass/Bonfire on HOME.

Use Quantize **Basic or Full** with a **seven-note scale**. Quantize Off and other scale sizes deliberately fall
back to single notes and show **AUTO?**. Switching to a supported scale resumes Auto. MIDI Direct remains direct
note playback. See [the complete Auto Harmony guide](../AUTO-HARMONY.md) for modifier conflicts, retrigger timing,
voicing, scale behavior and the six-note chord limit.

## Recording, settings and backups

Auto recording captures the actual notes and bass. Those recordings remain fixed when changing Harmony mode,
modifiers or key/scale later, including when pattern Follow is enabled. Existing Manual Follow behavior is preserved.

Legacy settings remain 188 bytes and pattern events remain 22 bytes. Manual chord forms, user sounds and saved
patterns are retained. Harmony preferences use their own checked/versioned record; backup object 68 carries it.
The included backup clients recognize this object. An older backup without it leaves existing Harmony preferences
alone, and an installation without a valid Harmony record defaults to Manual.

## Install

Download **`coralflower-0.6-chase5.fwsc`** from this release. Save a current backup before updating. In
<https://ficusficusov.github.io/CoralFlower/#own>, expand **Another version, or a build of your own**, choose this
`.fwsc` file, verify the selected filename, then install from that section. The installer defaults to upstream
CoralFlower; the separate app `.bin` and source archives are not installer packages.

The startup title remains **Chase FM-1**. INFO reports **`CoralFlower 0.6-chase5`**, preserving installer-family
recognition. The package stays `FM-1_930`; USB names and the existing loader/stub remain unchanged.

## Validation

This release is built from its tagged main source with the JieLi device toolchain, including linker-region,
protected-sector and package checks. Host checks cover Auto Harmony fixtures, controls, persistence, MIDI and
recording alongside the visuals, diagnostics, library, backup and storage suites. USB regression fixtures include
Auto thirteenth chords with bass at both capture rates, with FX and output-mode variations.

The release includes `SHA256SUMS`, licence files and the inspectable application image. Host and build checks do
not establish physical-device listening, USB enumeration or real-time workload limits; those remain checks on the
FM-1 after installation. Keep your current backup and the previous known-good package available.
