# CORD 1.0.1 — public branding and compatibility audit

- Browser and Python backups now download as `cord-backup-YYYYMMDD.json`. Backup labels use CORD; old CoralFlower archives and their metadata remain compatible.
- USB MIDI identifies as **CORD FM-1** and USB audio as **CORD In**. Re-select the renamed device in your DAW after updating.
- Native emulator ports, browser status/metadata, optional legacy boot text and installer wording consistently use CORD.
- CoralFlower and other upstream authors remain credited. Original licence/copyright notices, update identity, INFO family, storage formats and browser saves are preserved.
- Removed the obsolete upstream Pages publisher, corrected local emulator version selection, and added repeatable public-release audit checks to CI.
- Retains all CORD 1.0 features, including green PLAY / orange stopped and the next-root/Variations fixes.
