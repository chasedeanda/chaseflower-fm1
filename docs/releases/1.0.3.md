# CORD 1.0.3

Correct CORD’s identity to **FM-1_26730001**, with **ota-FM-1_26730001** in update mode. The Firmware Hub live identity checker reported this number free on 9 November 2026, including its reserved-range check. The previous 936 choice was absent from the current identities table but sits inside sloopDX’s reserved version range.

The package, app, loader and installer agree on the new identity. Earlier CORD/CoralFlower packages (930 and 936) remain installable through the CORD installer, with the final device identity verified against the selected package. Backups, browser saves, flash layout and the two-chip support from 1.0.2 are unchanged.

The Hub description now focuses on editable progressions and accompaniment. Hardware acceptance must use this exact release package; V15/custom-firmware install, switching away and interrupted-update recovery remain pending physical-device confirmation.
