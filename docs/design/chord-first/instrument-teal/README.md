# Selected interface reference

[Open the Instrument Teal review copy](prototype.html).

The supplied `fm1_adaptive_motion_prototype.html` is the chosen visual reference.
[The original](supplied-adaptive-motion-prototype.html) is preserved byte-for-byte;
[the manifest](manifest.json) records its SHA-256 and the review copy's three
default-theme changes. The user's Downloads files remain untouched.

**Default palette: Instrument Teal. Motion: On (adaptive) / Off.** Loudness and
playing-layer sliders simulate inputs to the adaptive response. This file has
no audio engine and is not flashed firmware. The 0–8 layer range is not a claim
about device capacity. Some Morph/Bloom and bank parameters remain visual studies.

Use [the implementation plan](../IMPLEMENTATION-PLAN.md) for the delivery order,
real control mappings, missing screen families and hardware acceptance gates.
The selected prototype owns the visual direction; canonical screen/workflow
definitions own the complete behavior, including Songs/direct recording,
learning, safe storage and retained advanced functions absent from this demo.
