# Approved soft mascot artwork

`devil-expressions.png` and `cat-expressions.png` are the original transparent
2×2 atlases generated with the built-in image-generation tool from the owner's
FM-1/CORD mascot concept boards. The reference boards are design inputs and are
not required to build. Each atlas is 1254×1254 and has the same four cells:

| Cell | Expression |
| --- | --- |
| Top left | Character's default face |
| Top right | Blink |
| Bottom left | Wink/grin for a fill or reaction |
| Bottom right | Relaxed face during a drum drop |

The owner selected only Devil/Ember and Cat/Plum. The approved floating-head
identity replaces the earlier full-body vector character. No cactus artwork is
included in the firmware source.

Final generation prompts specified:

- **Devil:** reproduce the exact Soft Blob/Ember identity in the supplied mascot
  refinement board: a compact, wide, squashed orange floating head, organically
  curved orange horns, black slanted mischievous eyes and a little curved smirk.
  Soft matte clay/3D shading with a peach upper-left highlight and burnt-orange
  underside. No body, neck, limbs, tail, white eyeballs, floor, text or UI. One
  transparent square 2×2 atlas with identical silhouette, scale, camera, palette
  and lighting, changing only default smirk, blink, gleeful wink/grin and relaxed
  closed-eye smile. Each sprite centered within its cell with transparent padding,
  readable at approximately 80px display width.
- **Cat:** reproduce the plum cat in the center panel of the supplied Soft Mascot
  Studio screenshot: a wide, rounded pink/plum/lilac floating head, rounded
  triangular ears, soft inner ears, black happy curved eyes, tiny black smile and
  exactly two ivory whiskers per cheek. The same sculpted upper-left lighting,
  deeper purple underside and no body/limbs/tail/floor. One transparent square
  2×2 atlas with consistent silhouette, scale and placement; default happy face,
  flatter blink, wink/open smile and relaxed closed-eye smile. No text, UI, frames,
  glows or separate background. Readable at approximately 80px display width.

`tools/gen_mascots.py` performs deterministic firmware encoding at 112×112 per
cell, composites edge coverage against the character's fixed background and
quantizes each character to one 60-colour palette. Transparent spans are omitted.
The original generated PNGs remain intact. The generated C header lives under
`build/gen/` and is regenerated by the normal build; it is not checked in.
