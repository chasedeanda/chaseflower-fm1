# ChaseFlower 0.6-chase3

Choose `chaseflower-0.6-chase3.fwsc` on the [custom-build installer](https://ficusficusov.github.io/CoralFlower/#own).

[Controls and installation](../../docs/CHASE3.md) · [Sound catalog](../../docs/CHASE3-SOUNDS.md) · [Verification](../../docs/CHASE3-VERIFICATION.md).

This audition candidate includes 96 chord/layer patches, 24 basses, eight kits, three 6/8 grooves, and HOME Chord/Keyboard views. Thirty-two voices are original CC0 Aquanode patches; original sources and licenses are in the repository.

The firmware build and host checks pass. Device listening and sustained performance need Chase's FM-1. No device has been flashed automatically.
